Data-Driven Robust Dynamic Wireless Charging Lane Planning with Tunable Profit--Risk Trade-off and Modified User Equilibrium

Xin Cui, Yujun Lin, Ziang Liu, Francis Yunhe Hou et al.
arXiv arXiv eess.SY2026-11-10 Transport-grid integration

Robust two-stage planning of dynamic wireless charging lanes with EV routing, SoC dynamics and coupled traffic-power networks directly fits transport-grid integration.

Abstract

Dynamic wireless charging (DWC) has attracted increasing attention as a complement to conventional plug-in charging for electric vehicles (EVs). However, existing planning methods for dynamic wireless charging lanes (DWCLs) overlook realistic EV routing and charging behavior and lack explicit out-of-sample risk control under traffic-demand and renewable-energy uncertainties. To address these limitations, this paper proposes a data-driven two-stage robust planning framework that coordinates DWCL deployment with the operation of coupled traffic--power networks (CTPNs). A data-driven uncertainty set is constructed from joint historical scenarios to preserve spatio-temporal correlations without imposing parametric distributional assumptions. A modified user-equilibrium (MUE) model is proposed to capture realistic EV routing and charging behavior by incorporating state-of-charge (SoC) dynamics and endogenous charging decisions. The resulting two-stage robust model with mixed-integer recourse is reformulated as an equivalent single-stage scenario-approach problem and solved using a customized nested column-and-constraint generation algorithm. An \textit{a posteriori} feasibility guarantee is established to quantify out-of-sample risk. Based on this guarantee, the scenario set is iteratively enriched to meet a prescribed risk tolerance. Case studies on a 69-node power distribution network and a 24-node traffic network demonstrate that the proposed MUE model prevents overinvestment in DWCLs, while the proposed risk-quantification procedure enables a tunable profit--risk trade-off.

Autonomous Optimization of Numerical Algorithms by an AI Agent: Application to Atomistic Simulation

Jeheon Woo
arXiv arXiv physics.chem-ph2026-11-09 AI for optimisation

An LLM coding agent in automated loops improves numerical optimizers that need fewer force evaluations, closely matching LLM-designed algorithms and agentic optimisation.

Abstract

Coding agents built on large language models, run in automated improvement loops, can discover more efficient algorithms. We present AIOA, a framework that brings this approach to the numerical algorithms of atomistic simulation: an agent improves an algorithm against a pre-specified metric in a loop guarded by verifiers it cannot alter. Applied to ASE, a widely used atomistic simulation library, AIOA targets two facets of an algorithm: its implementation, rewritten to run faster with unchanged results, and the method itself, redesigned to converge with fewer force evaluations. Agents made six kernels 22-24 times faster on average in Python with NumPy and SciPy. On unseen problems, optimizers from the best configuration needed 3.1-3.4 times fewer force evaluations than L-BFGS for structure relaxation and 4.6-17 times fewer than standard climbing-image nudged elastic band calculations for reaction paths. The agents' optimizers also contain two algorithmic components we did not find in the literature.

Contrastive Discovery: Open-Ended Scientific Discovery over Competing Explanations

Ziang Liu, James J. Kim, Yijia Dai, Jennifer J. Sun
arXiv arXiv cs.AI · NeurIPS 20262026-11-10 LLM & agentic AI

LLM discovery agents using contrast sets to choose experiments under budget is agentic decision-making with search guidance, adjacent to operational agents.

Abstract

LLM agents are increasingly used for open-ended, data-driven scientific discovery, yet most of them evaluate hypotheses pointwise, testing an empirical claim $h$ only against its complement $\neg h$. When evidence rejects $h$, the agent learns that one explanation is unlikely but not which alternative the evidence supports. To recover that alternative, we introduce Contrastive Discovery, which replaces the single hypothesis with a contrast set, a scientific question paired with mutually exclusive and collectively exhaustive competing explanations. Each experiment is scored by how its evidence redistributes belief across the set, and the question is resolved when belief concentrates on one explanation. Because contrast sets change only the unit an agent proposes and scores, an existing agent can use them to re-evaluate evidence it has already collected or to guide its search. Across six domains, $89\%$ of the pointwise candidates with the largest belief shifts are rejections. On the same evidence, contrast sets resolve $73\%$ of these candidates to a specific alternative. When contrast sets guide search, the agent resolves $67\%$ more questions than pointwise surprisal under the same experiment budget. In a blinded study, $38$ human experts chose the same explanation on $78\%$ of resolved questions and on $82\%$ of questions where the pointwise agent rejected its hypothesis and stopped. Together, these results support explicit competing explanations as a way for discovery agents to resolve more scientific questions from the same evidence and validation budget.

Data-driven regional traffic simulation from heterogeneous mobility sources

Federico Bellisardi, Chiara Mizzi, Alessandro Fabbri, Davide Micheli et al.
arXiv arXiv physics.soc-ph2026-11-10 Traffic simulation & calibration

Agent-based regional traffic simulator calibrated with heterogeneous mobility data and validated on held-out sensors; adjacent to the researcher's simulation and validation work.

Abstract

Regional traffic simulators increasingly combine mobile-phone, road-sensor and GPS data, but what each source contributes is rarely clear. We present an agent-based simulator of daily traffic in Emilia-Romagna, Italy: phone data give trips and their timing, half of the road sensors set the traffic level, all sensors correct it locally, and GPS traces guide route choice. We measure what each source adds against predictors without simulation, on sensors kept out of parameter calibration in winter 2020 and partly shared with it in summer 2021; as these sensors informed some modelling choices, the evaluation is not fully independent. Total traffic is within 1% of observations in winter and 10% in summer, and the simulator ranks roads better than a road-type predictor (Spearman 0.67-0.68 against 0.41-0.48, winter). GPS improves this ranking, sensors improve local estimates, and timing comes mostly from the demand. Single-road errors remain similar to those of simple predictors, and the test of specific origin-destination pairings was underpowered and inconclusive. These findings provide a practical framework for assessing the contribution and limitations of heterogeneous data sources in regional traffic simulation.

Discrete Model-Based Diffusion for Combinatorial Optimization in Multi-Robot Task Allocation

Haejoon Lee, Thomas Marshall Vielmetti, Xinyi Wang, Dimitra Panagou
arXiv arXiv cs.RO2026-11-09 AI for optimisation

Training-free discrete diffusion sampling for NP-hard multi-robot task allocation and scheduling, competitive with MILP; method-adjacent to combinatorial scheduling.

Abstract

Decision making in multi-agent and multi-robot systems often involves discrete decision variables, leading to NP-hard combinatorial optimization problems that must be solved within seconds for near real-time implementation. Denoising diffusion has emerged as a powerful tool for such problems, but existing approaches face a trade-off: Model-Based Diffusion (MBD) incorporates diffusion in sampling-based optimization (SBO) without training but only over continuous spaces, while existing diffusion-based combinatorial solvers operate over discrete spaces but require offline training. To this end, we propose Discrete Model-Based Diffusion (Discrete MBD), a training-free SBO method that directly optimizes discrete variables by approximating categorical reverse transition distributions through Monte Carlo sampling. We establish a finite-step lower bound on the probability of finding a global minimizer and show that this bound converges to one as the number of denoising steps increases. Extensive experiments on generic integer programs and heterogeneous multi-robot coalition formation and scheduling demonstrate that Discrete MBD outperforms SBO baselines in nearly all settings while achieving solution quality competitive with that of mixed-integer programming and reinforcement learning methods at a fraction of their computational cost.

Energy- and Time-Efficient Multi-Vehicle Trajectory Planning Using Augmented DAG Search in Configuration Space

Amirreza Akbari, Galina Sidorenko, Johan Thunberg
arXiv arXiv eess.SY2026-11-10 AI for optimisation

Energy-aware multi-vehicle trajectory planning with DAG search and MPC at intersections; energy-time trade-off and scalability relevant to vehicle scheduling.

Abstract

Multi-vehicle trajectory planning for CAV requires balancing energy consumption and travel time while ensuring safety and scalability. While travel-time-optimal methods based on Integer Programming exhibit poor scalability in large-scale multi-vehicle scenarios, existing energy-oriented approaches fail to balance energy consumption and travel time. We extend a configuration-space framework for multi-vehicle trajectory planning to jointly locally optimize travel time and energy consumption. A weighted energy-travel time objective is combined with an efficient augmented DAG search on two-dimensional decompositions of a high-dimensional configuration space, enabling scalable and collision-free coordination of large numbers of vehicles. Although the proposed framework is applicable to other traffic scenarios, such as roundabouts and vehicle-following, we focus on intersections as a representative and challenging planning problem. To further improve performance for our methodology, we also extend the method with an insertion-ordering heuristic that exploits reduced-space geometric information. Combined with nonlinear model predictive control, the proposed framework is shown to scale to 40 vehicles, outperform MILP-based and convex optimization baselines in dense intersections, and reduce energy consumption at equalized travel times relative to time-optimal planning.

EngineAgent: Agentizing On-Device LLM Inference Engines with Inference Stack Hierarchy Awareness and Hardware Abilities

Zhengxiang Huang, Yujie Sun, Shengheng Chen, Zhaode Wang et al.
arXiv arXiv cs.OS2026-11-10 LLM & agentic AI

Agentic system automating cross-layer LLM engine enablement with iterative debugging is a relevant agent-for-engineering workflow, not transport or optimisation.

Abstract

Rapidly evolving LLM architectures and heterogeneous mobile hardware make supporting new models in on-device inference engines a recurring and costly system challenge. Each model may require coordinated changes across conversion, graph construction, operators, and hardware backends. Existing coding agents often miss these cross-layer dependencies and struggle to diagnose failures across host--device execution paths. We present EngineAgent, an agentic system for automating on-device LLM model enablement. Its key insight is to separate reusable engine and hardware knowledge from model-specific implementation. Before enablement, EngineAgent constructs a hierarchy-aware engine index that captures engine abstraction layers and cross-layer dependencies, and pre-validates backend-specific build, execution, and debugging workflows using already supported models. For each new model, a builder uses this knowledge to coordinate cross-layer changes, while an auditor checks implementation completeness and drives iterative debugging through device-side validation. Across 12 tasks spanning three mobile LLMs and four engine--backend pairs on CPUs, GPUs, and NPUs, EngineAgent achieves 75% end-to-end success with either of two underlying LLMs, versus 33.3% for the strongest coding-agent baseline. Success requires compilation, on-device execution, and output-logit agreement with reference implementations. EngineAgent also reduces average per-task time and model-API cost relative to baselines using the same underlying LLMs.

From Questions to Decisions: Benchmarking How LLM Agents Acquire Decision-Relevant Information from Human Beings

Yuhan Tang, Ke Fan, Xinkai Zou, Baichuan Mo et al.
arXiv arXiv cs.AI2026-11-09 LLM & agentic AI

Benchmarks LLM agents planning optimisation-based schedules like driver assignment and asking for missing decision information, relevant to agentic operational decisions.

Abstract

LLM agents are increasingly asked to make plans for people, such as scheduling drivers or assigning nurses. However, people's requests are often incomplete, and the supporting information for decision-making may be outdated, requiring agents to ask for clarification. Existing benchmarks typically provide fully specified problems or rely on uncalibrated LLM-simulated users, leaving this ability insufficiently tested. We introduce Ask2Decide, a benchmark of 43 planning tasks that evaluates whether agents ask for missing information that matters for their decisions. An operator holds facts absent from the agent's request and records, and optimization solvers determine which facts change the optimal plan. We also include similarly worded facts that leave the optimal plan unchanged to test whether agents distinguish useful information from irrelevant details. We collect 79 interaction sessions from 19 participants and find that, after an incorrect plan, human replies omit the correcting fact far more often than replies from an uncalibrated simulated user (43% versus 7%). Using these interactions, we calibrate a simulated operator that more closely matches human reply patterns. Evaluating four frontier LLMs, we find that their initial plans are infeasible on 58-98% of tasks when information is missing, compared with 5-28% when all facts are provided upfront. Agents uncover facts that change the optimal plan only slightly more often than facts that leave it unchanged (39-52% versus 32-41%). These results show that obtaining decision-relevant information through interaction remains a major bottleneck for LLM planning. This is ongoing work and will be updated. PARLEY: Evaluating LLM Collaboration Through Cooperative Asymmetric Puzzles

Javier Hernandez, Andrew D. Wilson
arXiv arXiv cs.MA2026-11-10 LLM & agentic AI

Studies failure modes of collaborating LLM agents in cooperative tasks and derives a taxonomy; relevant to multi-agent reliability but not optimisation or transport.

Abstract

As large language models power autonomous agents, understanding how they collaborate and where they fail becomes critical. We introduce PARLEY, an extensible platform for studying LLM agent collaboration through four asymmetric puzzle tasks grounded in cognitive psychology (referential communication, joint coordination, perspective-taking, and spatial reasoning). GPT-4o agent pairs succeeded in 60.5% of conversations (N=400, 100 per task), with task-level variation (34-80%) reflecting distinct collaborative demands. From these conversations, we derived the data-driven PAC taxonomy: six failure types organized into Perception (visual interpretation and spatial reasoning), Adaptation (progress tracking and feedback integration), and Coordination (verification and grounding). Failure to incorporate external feedback was a critical indicator of unsuccessful collaboration, with agents repeatedly applying unsuccessful strategies. We also show that a taxonomy-guided intervention (N=200) improved average task success to 70.5%. These results demonstrate how PARLEY can be used to derive meaningful, data-driven insights that can in turn lead to improved agentic collaboration.

Teaching the Harness: Student-Aware Skill Transfer for LLM Agents

Chang Liu, Bo Wu
arXiv arXiv cs.AI2026-11-09 LLM & agentic AI

Teacher LLM builds student-aware skills for LLM agents with a tool harness and action budget; agentic method relevant to the researcher's agent work.

Abstract

Effective teaching requires reasoning about the learner as well as the task, a capacity that Theory of Mind describes as inferring another agent's latent state from its behavior. We ask whether a stronger LLM teaches a fixed student better when it applies this principle. The student is an LLM agent acting through a harness that fixes its tools, context, and action budget, so a procedure that helps one model can exhaust the budget of another. We introduce Student-Aware Teaching (SAT). The teacher builds a learner model that pairs an empirical profile with hypotheses about the student's limitations, tests these hypotheses with diagnostic probes, and writes reusable skills for the diagnosed failures. A skill enters the library only after it raises success on matched development tasks. With Claude-Sonnet-5 teaching DeepSeek-V4-Flash, SAT reaches 86.46% task success across four primary runs, leading both a profile-free teacher with the same framework (81.04%) and the untaught student (75.00%) in each run. Removing the analytical learner model lowers both prediction and success, and under misleading learner profiles none of the 48 candidate skills passes admission. When DeepSeek-V4-Flash and Gemini-3.8-Flash exchange libraries, each performs better with its own. Saved libraries keep average gains of up to 11.1 points after the teacher leaves. The benefit depends on a student that can follow instructions and a deployment route that delivers them.

Unified Optimization of Traffic Signal and Lane Channelization for an Isolated Intersection Using Reinforcement Learning

Jiwon Kang, Jiyoung Kim, Hyunseok Jun, Keemin Sohn
arXiv arXiv cs.LG2026-11-10 AI for optimisation

Deep Q-network jointly optimising traffic signals and lane channelization, a RL approach to a joint MILP-style design problem; adjacent to the researcher's interests.

Abstract

Optimizing traffic signal control has been a long-lasting critical issue in traffic engineering, and a number of robust methodologies have emerged to solve the problem so far. On the other hand, the road design for lane channelization is a static problem that is difficult to solve jointly with the real-time traffic signal control. If traffic volume does not vary, it is possible that both problems can be solved in an integrated manner as a single static optimization problem. Recently, researchers have devised a mixed integer linear problem (MILP) to jointly determine the traffic signal and road width designs. However, this joint optimization problem must be solved repeatedly whenever the traffic flow pattern varies. Solving the MILP may also take impractical computing time as the problem size gets larger. We present a robust methodology for solving the joint optimization problem using reinforcement learning (RL) on a real-time basis. Abrupt changes in lane markings with an incompatible signal phase can jeopardize drivers. To sidestep such a dangerous action change, we train a model with human feedback to filter infeasible action transitions in a rule-based manner. We devised a deep Q-network that can accommodate joint actions for traffic signal and lane marking plans. To ensure the implementation of the proposed operation, a variable sign for lane markings is necessary at each stop line of an intersection. The experimental results confirm that the proposed methodology enhances the intersection performance by increasing throughput.
